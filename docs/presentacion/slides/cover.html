Cachitos

El puesto de Lupita: una serie vertical para entender fracciones, que cambia según el error de cada estudiante.

Presentamos Cachitos, una serie vertical al estilo TikTok para que estudiantes de 1.º básico en Guatemala entiendan fracciones. La clave: si fallan un reto, el siguiente episodio ataca su error exacto.
